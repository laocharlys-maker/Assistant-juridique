# Aurore Mobile — Guide en une page

## Installer l'application

1. Reçois le lien d'installation (envoyé par le cabinet).
2. Ouvre-le sur ton téléphone Android et appuie sur **Installer**.
3. Si Android affiche un avertissement "Source inconnue" : c'est normal (l'application n'est pas encore sur le Play Store pendant le pilote) — autorise l'installation.

## Se connecter à Aurore (une seule fois)

1. Sur l'ordinateur du cabinet, ouvre **Aurore → Appareils mobiles** et clique sur **Générer un QR**.
2. Sur le téléphone, ouvre Aurore Mobile et scanne ce QR avec la caméra.
3. Un titulaire doit **autoriser** ton appareil depuis l'ordinateur (une notification apparaît côté Aurore Desktop).
4. Choisis un code à 4-8 chiffres pour déverrouiller l'application — à retenir, il te sera redemandé à chaque ouverture (après un court délai d'inactivité).

## Faire ton premier enregistrement

1. Depuis l'accueil, appuie sur **🎙️ Après audience**.
2. Choisis le dossier concerné (ou laisse "à classer" — tu pourras le faire plus tard).
3. Appuie sur le gros bouton pour démarrer. Un repère ("Prochaine audience", "Décision", "À faire", "Point important") se pose en un tap, sans jamais interrompre l'enregistrement.
4. Appuie sur **Terminer** quand c'est fini.

L'enregistrement part automatiquement vers Aurore dès que tu es connecté au Wi-Fi du cabinet — tu peux suivre son statut dans **"Mes éléments"** (en attente → envoyé → confirmé). Il reste sur ton téléphone tant qu'Aurore n'a pas confirmé l'avoir bien reçu : **rien n'est jamais perdu**, même si le Wi-Fi coupe en plein envoi.

## Scanner un document ou écrire une note

- **📄 Scanner** : prends la photo, ajuste les 4 coins du document toi-même (pas de détection automatique), ajoute d'autres pages si besoin, puis choisis le type (Pièce, Décision, Courrier...) et le dossier.
- **📝 Note** : texte libre, rattaché à un dossier ou à un enregistrement/scan déjà fait.

## Si tu perds ton téléphone

1. **Préviens immédiatement le titulaire du cabinet.**
2. Depuis Aurore Desktop (**Appareils mobiles**), le titulaire **révoque** ton appareil en un clic — l'accès est coupé instantanément, où que soit le téléphone.
3. Les enregistrements déjà envoyés et confirmés restent en sécurité dans Aurore. Ceux encore "en attente" sur le téléphone perdu ne peuvent plus être récupérés — c'est le compromis du chiffrement : aucune donnée sur le téléphone n'est lisible par qui que ce soit sans le déverrouiller d'abord, toi y compris si tu changes d'appareil.
4. Pour continuer à travailler : installe Aurore Mobile sur un nouveau téléphone et réappaire-le comme la première fois.

## Ce qu'Aurore Mobile protège, et ce qu'il ne protège pas

**Protégé** : aucune donnée en clair n'est accessible sans déverrouiller l'app ; rien n'est envoyé ailleurs qu'à l'ordinateur du cabinet ; aucune capture d'écran possible pendant l'usage ; aucune photo/audio ne finit dans ta galerie.

**Non protégé** : un téléphone déjà infecté par un logiciel malveillant, un appareil "débridé" (root) de façon dissimulée, ou le fait de partager toi-même un fichier hors de l'application (capture avec un autre appareil, par exemple) — aucune application ne peut se protéger contre ça. Aurore Mobile n'est **pas garanti "100 % sécurisé"** — c'est une protection sérieuse contre les risques courants, pas une assurance absolue.
