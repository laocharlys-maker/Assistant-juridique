Utiliser l'adresse par nom d'hôte en priorité (fonctionne même si l'IP change) ; l'adresse IP directe reste une solution de secours si le réseau du cabinet bloque la résolution mDNS. Voir README-LOT6.md.

Poste unique

Aurore fonctionne uniquement sur cet ordinateur.

  • Aucun accès depuis un autre poste
  • Aucune configuration réseau nécessaire
  • Recommandé par défaut

Serveur réseau

Ce poste sert Aurore aux autres ordinateurs du cabinet.

  • Les autres postes se connectent via leur navigateur
  • Nécessite une configuration réseau (pare-feu)
  • Voir README-LOT6.md pour la procédure complète
En mode réseau, l'application sera accessible par tous les postes de votre réseau local (Wi-Fi/câblé du cabinet). Assurez-vous que ce réseau est privé et sécurisé.

Configuration enregistrée

Veuillez fermer puis rouvrir Aurore pour appliquer ce changement.

Étapes suivantes pour le mode réseau (voir README-LOT6.md) :

  • Exécuter installer/firewall-rule.ps1 sur ce poste (ouvre le port sur le profil réseau privé uniquement)
  • Redémarrer Aurore : le certificat HTTPS local sera généré automatiquement
  • Importer le certificat sur chaque poste client (voir installer/import-cert-instructions.md)
