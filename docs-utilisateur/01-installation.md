# Installer Aurore sur votre ordinateur

> **Note pour qui prépare ce guide** : les emplacements marqués
> `[Capture d'écran : ...]` doivent être remplacés par une vraie image une
> fois qu'un premier installeur réel a été construit — voir
> `README-LOT8.md` pour l'explication.

## Ce dont vous avez besoin

- Un ordinateur avec Windows 10 ou Windows 11.
- Le fichier d'installation d'Aurore, reçu d'AzoMedIA (un fichier qui
  ressemble à `Aurore_1.0.0_setup.exe`).
- Environ 5 minutes, sans avoir besoin d'installer quoi que ce soit
  d'autre au préalable.

Vous n'avez besoin d'aucun compte technique, d'aucun logiciel
supplémentaire à télécharger. Tout ce dont Aurore a besoin est inclus
dans ce seul fichier.

## Étape 1 — Lancer l'installation

Double-cliquez sur le fichier reçu d'AzoMedIA.

Si Windows affiche un message bleu **"Windows a protégé votre ordinateur"**,
c'est normal pour un nouveau logiciel qui n'est pas encore largement connu
de Windows — cliquez sur **"Informations complémentaires"**, puis sur
**"Exécuter quand même"**.

`[Capture d'écran : message Windows SmartScreen et bouton "Exécuter quand même"]`

## Étape 2 — Accepter les conditions d'utilisation

Un texte s'affiche, expliquant les conditions d'utilisation d'Aurore.
Lisez-le, puis cochez la case et cliquez sur **"Suivant"**.

`[Capture d'écran : écran des conditions d'utilisation]`

## Étape 3 — Choisir l'emplacement (facultatif)

Un emplacement par défaut est déjà proposé. Sauf raison particulière,
laissez-le tel quel et cliquez sur **"Installer"**.

`[Capture d'écran : écran de choix de l'emplacement]`

## Étape 4 — L'installation se déroule automatiquement

Une barre de progression s'affiche pendant quelques instants. Vous n'avez
rien à faire — aucune fenêtre technique supplémentaire ne doit apparaître
pendant cette étape.

À la fin, un message vous rappelle une bonne pratique de sécurité
(l'activation du chiffrement de disque BitLocker de Windows, si votre
ordinateur contient des dossiers de clients). C'est une simple
recommandation, pas une obligation immédiate — vous pouvez continuer.

`[Capture d'écran : message de fin d'installation]`

## Étape 5 — Premier lancement

Une icône **Aurore** apparaît sur votre Bureau. Double-cliquez dessus pour
lancer l'application pour la première fois.

Vous arrivez sur un écran de **bienvenue**, qui vous guide vers les deux
dernières étapes avant de pouvoir travailler :

1. Choisir comment cet ordinateur sera utilisé (voir le guide
   `03-connexion-postes-reseau.md` si plusieurs personnes du cabinet
   doivent utiliser Aurore).
2. Activer votre licence (voir le guide `02-activation-licence.md`).

`[Capture d'écran : écran de bienvenue Aurore]`
