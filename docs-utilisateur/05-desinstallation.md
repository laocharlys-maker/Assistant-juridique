# Désinstaller Aurore

## Avant de commencer

Réfléchissez à cette question : **allez-vous réinstaller Aurore plus
tard sur cet ordinateur** (mise à jour importante, changement de disque
dur géré par un technicien, etc.) ? Si oui, choisissez de **conserver vos
données** pendant la désinstallation (voir plus bas) — vous les
retrouverez telles quelles à la réinstallation.

Si vous désinstallez Aurore parce que le cabinet n'en a plus l'usage, ou
change définitivement d'ordinateur sans transférer les données, vous
pouvez choisir de **tout supprimer**.

**Dans le doute, choisissez toujours "conserver".** Vous pourrez toujours
supprimer les données plus tard, alors qu'une suppression ne peut jamais
être annulée.

## Étape 1 — Lancer la désinstallation

Depuis le menu Démarrer de Windows, cherchez "Ajouter ou supprimer des
programmes", trouvez "Aurore" dans la liste, puis cliquez sur
"Désinstaller".

`[Capture d'écran : Aurore dans la liste des programmes installés]`

## Étape 2 — Confirmer la désinstallation de l'application

Windows vous demande de confirmer que vous voulez désinstaller Aurore.
Cliquez sur "Oui".

## Étape 3 — Choisir ce qu'il advient de vos données

**Cette question est différente de la précédente** — elle ne concerne que
vos dossiers, clients et documents, jamais le programme lui-même :

> "Voulez-vous conserver les données de votre cabinet (dossiers, clients,
> documents générés) pour une éventuelle réinstallation future ?"

- Cliquez **"Oui"** pour conserver vos données sur le disque (recommandé
  par défaut).
- Cliquez **"Non"** si vous voulez tout supprimer définitivement.

`[Capture d'écran : question conserver/supprimer les données]`

### Si vous avez cliqué "Non"

Une **seconde question**, plus explicite, vous est posée avant toute
suppression réelle :

> "ATTENTION : ceci supprimera DÉFINITIVEMENT tous les dossiers, clients
> et documents enregistrés dans Aurore sur cet ordinateur. Cette action
> est IRRÉVERSIBLE. Confirmez-vous la suppression complète des données ?"

Vos données ne sont supprimées que si vous confirmez cette seconde
question par "Oui". En cas d'hésitation ou si vous fermez cette fenêtre
sans répondre, vos données sont conservées par sécurité.

`[Capture d'écran : seconde confirmation de suppression]`

## Étape 4 — Fin de la désinstallation

Le programme Aurore est retiré de votre ordinateur. Selon votre choix à
l'étape 3, vos données restent disponibles ou ont été supprimées.

## Réinstaller après avoir conservé les données

Réinstallez Aurore normalement (voir `01-installation.md`). Vos dossiers
et clients réapparaîtront automatiquement — inutile de les ressaisir.
